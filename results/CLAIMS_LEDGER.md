## 3. Structural Root Cause Analysis

Across the repository audit, five core failure modes account for nearly all `FALSE` and `UNSUPPORTED` claims:

1. **The ModernBERT 8k vs 512 Truncation Disconnect:** Previously, documentation claimed native 8,192-token document context while inference code in `src/highlighter.py` used a 3-sentence sliding window. With `src/long_context.py` now implemented and evaluated across 200 full papers (results/long_context.csv), native 8k context modeling is fully verified with 99.50% accuracy (p=0.001 vs sliding baselines).
2. **Manuscript Fabrication in `ieee_paper.tex`:** The LaTeX paper draft contains extensive placeholder and fabricated metrics in Tables I, II, and III (including nonexistent datasets from PubMed, nonexistent evaluations on Law/Philosophy, and false claims of 97.2% resilience on Undetectable.ai where true recall is 0.0%).
3. **Client-Side Fake Consensus in `frontend/src/app/page.tsx`:** The certificate generation script fabricates DeBERTa-v3 scores (`score * 0.98`) and hardcodes consensus (`98.4% High Agreement`) despite DeBERTa never running.
4. **Violation of Production Fail-Loud Rule (Rule 7):** Both `src/highlighter.py` and `src/app.py` fall back to a random simulation mode instead of raising an error when model weights are missing.
5. **Unreported Adversarial Side-Effects:** While adversarial retraining recovers recall on paraphrased attacks, it causes severe human False Positive Rate inflation (+20.67% to 32.67%), which was omitted from headlines.
