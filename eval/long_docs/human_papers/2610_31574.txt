ABSTRACT
Sequence compression is a fundamental operation and a critical information bot-
tleneck in efficient language and multimodal models, and yet prevailing ap-
proaches based on pooling or learned projections remain underperforming. We
revisit sequence compression through the lens of test-time regression: input tokens
define a regression problem whose fitted coefficients form the compressed repre-
sentation. Importantly, the regression problem is learned end-to-end via back-
propagation, while its coefficients are computed efficiently in closed form during
the forward pass. This leads to TTR-Compressor, a general alternative to conven-
tional pooling and projection-based compression. We evaluate TTR-Compressor
as the compressor for block-wise sparse attention and the visual token merger
for multimodal large language models. On block-wise sparse attention, TTR-
Compressor improves RULER performance over attention-based compressors by
a large margin. For visual token merging, it consistently outperforms the stan-
dard MLP merger and matches its performance with 55.6% fewer visual tokens.
These results establish test-time regression as an effective primitive for sequence
compression in efficient language and multimodal models.

Sequence compression is a ubiquitous operation in modern efficient large model architectures (Qwen
Team, 2026b; DeepSeek-AI, 2026), and yet remains surprisingly underexplored.
For example,
block-wise sparse attention compresses each token block into a summary vector used to score and

select relevant blocks (Jiang et al., 2024; Lu et al., 2025; Yuan et al., 2025), while multimodal large
language models (MLLMs) merge neighboring visual features into compact tokens before feeding
them into the language backbone (Wang et al., 2025; Bai et al., 2025; Team et al., 2026a). In both
settings, the compressor acts as a critical information bottleneck. Once information is discarded,
it cannot be recovered downstream. One would expect compression to be a carefully designed ar-
chitectural component. However, most models rely on simple mechanisms, such as parameter-free
pooling, learned projections over concatenated tokens, or at best, attention-weighted pooling.
We argue that these default compressors share a fundamental structural limitation, i.e., they aggre-
gate tokens using weights that do not account for inter-token relationships. Mean pooling uses
uniform weights, linear projection uses fixed position-dependent weights, and attention-weighted
pooling scores each token independently. As a result, redundant tokens can reinforce one another,
while distinctive information is diluted. From a statistical perspective, these methods primarily
exploit first-order token statistics while ignoring second-order inter-token correlations, the very
structure that reveals which information is redundant and which is distinctive.
We introduce a fundamentally different compression strategy. Rather than asking which weighted
average best summarizes a set of tokens, we let the tokens define a regression problem and take its
fitted coefficients as the summary. Specifically, our proposed TTR-Compressor, constructs a self-
supervised ridge-regression problem directly from the input tokens, requiring no external labels,
and uses its closed-form solution as the compressed representation. This formulation creates a nat-
ural division: the outer training loop meta-learns which regression problem produces task-useful
representations, while the inner closed-form solution determines how that problem should be fitted
to each input. The key distinction from conventional pooling and projection arises from the Gram
matrix in the regression solution. By explicitly capturing inter-token correlations, TTR-Compressor
fits correlated tokens jointly, so redundant evidence has diminishing rather than purely additive in-
fluence. This input-adaptive behavior cannot be reproduced by a fixed projection or additive token
combination. Moreover, learning the regularizer removes the need for ridge hyperparameter tuning
in large-scale pretraining. Because the compression window is typically smaller than the channel
dimension (i.e., T < d), we solve the dual problem with an efficient T × T Cholesky factorization.
Thus, TTR-Compressor incurs minimal overhead and introduces only 2d learnable parameters per
compressor, making it an effective drop-in replacement for sequence compression.
We evaluate TTR-Compressor on two applications that impose fundamentally different requirements
on compression. In block-wise sparse attention, the compressed summary must act as a faith-
ful retrieval key. In this setting, TTR-Compressor consistently outperforms traditional baselines
on RULER (Hsieh et al., 2024) retrieval tasks, surpassing sophisticated attention-based compres-
sors (Hu et al., 2026) by a considerable margin. In visual token merging, by contrast, the compressed
summary must preserve a faithful representation. Here, TTR-Compressor consistently outperforms
the widely used MLP merger across diverse compression ratios, and achieves comparable perfor-
mance with 55.6% fewer visual tokens. Our contributions are summarized below:
• A novel compression framework. We introduce a test-time regression framework for sequence
compression, reframing token summarization as an instance-adaptive optimization problem.
• A practical operator. We derive an efficient dual closed-form solution and eliminate hyperpa-
rameter tuning, making TTR-Compressor fully practical and scalable for large-scale pretraining.
• Empirical effectiveness. As a drop-in component in large models, TTR-Compressor consistently
outperforms conventional baselines in both block-wise sparse attention and visual token merging.

RELATED WORK
Sequence compression. Compressing a sequence of tokens into a single vector is a fundamen-
tal operation across modern architectures, with applications ranging from multimodal token reduc-
tion (Bolya et al., 2022; Li et al., 2023; Yao et al., 2024; Cha et al., 2024; Chu et al., 2024) to
block-wise sparse attention (Jiang et al., 2024; Lu et al., 2025; Gao et al., 2024; Lai et al., 2025).
Existing compression operators largely fall into three paradigms: (1) parameter-free pooling, such
as mean pooling; (2) concatenation followed by learned projection; and (3) attention-based com-
pression, which summarizes tokens via attention-weighted averaging (Mohtashami & Jaggi, 2023;
Yang et al., 2025b). A fundamental limitation of these families is that they compute token combi-
nations without explicitly accounting for the inter-token correlations. In contrast, TTR-Compressor
2

derives its representation as the solution to a linear system whose Gram matrix directly encodes
these correlations, providing an expressive, drop-in replacement for the operators above.
Test-time regression and test-time training. The idea of adapting part of a network on each input
at inference time dates back to fast-weight programmers (Schmidhuber, 1992; Schlag et al., 2021)
and was revived as test-time training (TTT), first for robustness under distribution shift (Sun et al.,
2020) and then as sequence-modeling layers whose hidden states are small models updated by gra-
dient descent on a self-supervised loss (Sun et al., 2024; Behrouz et al., 2026b;a; Han et al., 2026).
In-Place TTT (Feng et al., 2026) further extends this paradigm by directly adapting the existing
MLP projection weights of pretrained Transformers. A parallel line of work reinterprets linear at-
tention and its descendants (e.g., DeltaNet (Yang et al., 2024), Gated DeltaNet (Yang et al., 2025c),
Longhorn (Liu et al., 2025), Titans (Behrouz et al., 2026b)) as online regression: each layer main-
tains a key-to-value regressor that is refined with one gradient or delta-rule step per token and read
out by the query. MesaNet (von Oswald et al., 2026) pushes the inner optimization to convergence,
solving the problem at every time step with conjugate gradients, while LaCT (Zhang et al., 2026)
updates fast weights over large, unordered chunks to improve hardware utilization.
TTR-Compressor differs from these methods in two fundamental ways. First, because compression
operates independently on small, disjoint blocks without cross-block dependencies, the regression
admits an efficient, exact closed-form solution via a single T × T dual solve. This avoids both iter-
ative gradient-based inner optimization (as in TTT, ViT3, In-Place TTT, and MesaNet) and single-
step approximations (such as delta-rule updates). Second, rather than using test-time regression to
produce input-dependent model weights (Bertinetto et al., 2018; Sun et al., 2020) or a fast-weight
memory that is subsequently queried (Schlag et al., 2021; Yang et al., 2025c; Behrouz et al., 2026b),
we use regression to directly yield a representation of a token block. Specifically, the fitted coeffi-
cients themselves serve as the compressed representation (e.g., a visual token or a retrieval key).

JOINT SEQUENCE COMPRESSION VIA TEST-TIME REGRESSION
We introduce TTR-Compressor, a sequence compression operator based on test-time regression, as
shown in Figure 2(a). Given a sequence of token representations, TTR-Compressor constructs a
regression problem from the tokens and uses its fitted coefficients as the compressed representation.
We first present the regression formulation of compression and specify its construction, then derive
an efficient solution and describe how TTR-Compressor is learned end-to-end within a model.
3.1
COMPRESSION AS TEST-TIME REGRESSION
We formulate sequence compression as ridge regression (Hoerl & Kennard, 1970). The tokens in a
sequence provide regression observations, and the fitted regression coefficients serve as a compact
representation of that sequence. The regression objective encourages this representation to capture
the relationships among tokens, while regularization controls the magnitude of the fitted coefficients.

into a single vector h ∈Rd. We associate each token with a regression key kt ∈Rd and a scalar
target vt ∈R, and define the compressed representation as:

3.4
FULLY END-TO-END TRAINING
The target projection a and diagonal parameters ρ are optimized end-to-end through the differen-
tiable closed-form solution using the original model’s training objective. Each compressor main-
tains its own parameters, which are shared across all input sequences. At inference time, these
learned parameters remain fixed, while h⋆is recomputed independently for each input sequence.
TTR-Compressor therefore combines a learned regression objective with an exact, input-adaptive
solution, without requiring iterative gradient-based optimization at test time.

The learning process of TTR-Compressor can be decomposed into two distinct mechanisms: outer-
loop training learns which regression problem is useful for compression, while the inner solution
adapts the compressed representation to the current input’s statistics. We examine them separately.

APPLICATIONS AND EXPERIMENTAL RESULTS
We evaluate TTR-Compressor in two settings: block-wise sparse attention for efficient language
modeling, where compressed representations guide context selection, and visual token merging for
efficient multimodal understanding, where they serve as the visual input to the language backbone.
5.1
BLOCK-WISE SPARSE ATTENTION
Architecture and Baselines. Block-wise sparse attention partitions the context into blocks, scores
their compressed representations against each query, and attends to tokens in selected blocks along-
side a local window. The compressor therefore determines which distant information remains ac-
cessible: an uninformative summary can prevent a relevant block from being selected, regardless of
the quality of its individual token representations.
We adopt HiLS-Attention (Hu et al., 2026) as a base framework and vary only the compressor. HiLS-
Attention has three effective architectural components: hierarchical softmax attention, which com-
bines within-block attention with learned block-level weights; low-rank query calibration, which
adapts queries for scoring compressed representations; and HoPE, which applies RoPE to only a
subset of feature dimensions to support length extrapolation. We compare four compressors: mean
pooling, concat & projection, the attention-weighted pooling used in the original HiLS-Attention,
and TTR-Compressor. Full attention and sliding-window attention serve as additional references.
Training and Evaluation.
We train 345M-parameter language models on the FineWeb
dataset (Penedo et al., 2024) with an 8K context length. Training runs for 30,000 optimization
steps with a global batch size of 128 sequences, corresponding to approximately 30B tokens, and
uses AdamW with a learning rate of 3 × 10−4. All sparse attention variants use 64-token blocks,
select up to 32 distant blocks per query, and retain a 512-token local window.
Evaluation covers two complementary aspects. First, since queries use the compressed represen-
tations to retrieve relevant blocks, retrieval accuracy directly reflects compression quality. Follow-
ing (Hatamizadeh et al., 2026), we evaluate on the single-needle (S-NIAH) and multi-key (MK-
NIAH) retrieval tasks from RULER (Hsieh et al., 2024), which require locating relevant information
