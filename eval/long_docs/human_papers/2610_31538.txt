ABSTRACT
Local anomaly detection is the task of identifying spatially confined anomalous
or out-of-distribution (OOD) regions within an otherwise in-distribution (ID) im-
age. Most existing methods are designed for a specific context, with a strong
focus on industrial defect detection, where they achieve excellent performance
on well-established benchmarks. However, we observe that these methods can
exhibit significant performance drops in other contexts, especially when the inlier
distribution is multimodal. To account for this inlier complexity, we propose LAC-
ToS, a principled local OOD detection method based on statistical typicality and
made tractable through two innovations: (i) grouping pixels into superpixels and (ii)
using a computationally efficient proxy to estimate typicality. We evaluate LACToS
across three diverse applications spanning medical imaging, human faces, and X-
ray security screening. LACToS performs more robustly than prior methods across
these benchmarks. The code is released here: https://github.com/voilalab/LACToS.

Prior work on localized anomaly detection has largely followed representation-based and
reconstruction-based approaches. Representation-based methods extract local features from normal
(inlier) training images, and score test patches using their distance from the learned distribution or their

likelihood under it (Cohen and Hoshen, 2020; Defard et al., 2021; Roth et al., 2022). Reconstruction-
based methods instead reconstruct, inpaint, or denoise the target image under a prior for inlier images,
and use the discrepancy between the input and its reconstruction as an anomaly signal (Mousakhan
et al., 2024; Wu et al., 2024). Although both approaches have achieved strong empirical performance,
especially for industrial defect detection (Bergmann et al., 2019), their anomaly scores are often
heuristic: representation-based methods depend on the choice of feature and distance metric, while
reconstruction-based methods typically collapse the distribution of inlier completions into a point
estimate. Conformal and risk-control methods can provide statistical guarantees for calibrated seg-
mentation outputs (Shen and Liu, 2025), but they generally rely on a large amount of OOD calibration
data. Moreover, we empirically observe that these methods do not always generalize reliably beyond
industrial defect detection.
We present LACToS, a statistical method for local OOD detection that is designed to address these
limitations of existing methods. Our approach is fundamentally reconstruction-based, but uses the
key insight that the distribution of the reconstructions contains valuable information that is lost
when reconstruction error is computed using a single sample or an aggregated point estimate. To
leverage this richer distributional information towards improved local anomaly detection, we propose
an anomaly metric based on statistical typicality, a measure of how representative a sequence of
observations is for a given distribution. Our use of typicality is inspired by previous typicality-based
OOD detection methods (Nalisnick et al., 2019; Osada et al., 2023; Barkley et al., 2026). However,
these works are focused on image-level OOD detection where an entire image is classified as OOD,
and to the best of our knowledge, using typicality for local anomaly detection has not yet been
explored.
We begin with the typicality score of Nalisnick et al. (2019), and adapt it to identify local rather
than whole-image anomalies (Section 4.1). Instead of asking whether an entire image is typical with
respect to the unconditional prior distribution, we ask whether each pixel is typical with respect to the
inpainting posterior conditioned on all other pixels in the image. However, this substitution induces
three major challenges: (i) failure to detect larger local anomalies that span multiple contiguous
pixels, (ii) loss of statistical validity, because typicality testing requires sampling a sequence of i.i.d.
observations, and (iii) prohibitive computational cost of performing posterior sampling separately for
each pixel.
LACToS tackles these challenges through two innovations: we partition images into superpixels
and replace pixel-level typicality with superpixel-level typicality (Section 4.2), and we use a single
denoising posterior as a common proxy for all inpainting posteriors. Our use of superpixels addresses
challenges (i) and (ii), because a local OOD feature is more likely to be captured by a superpixel than
a single pixel, and the individual pixels in each superpixel can be treated as independent observations
to evaluate superpixel-level typicality. Our use of denoising rather than inpainting addresses challenge
(iii), by dramatically reducing the number of posterior samples needed to estimate typicality. Through
these innovations, we show that LACToS achieves strong quantitative and qualitative performance
across a wide range of local OOD detection tasks including detecting tumors in CT scans, detecting
unusual facial accessories in photographs, and detecting weapons in X-ray baggage scans.
To summarize, we propose LACToS, a statistical approach to local OOD detection in images using
an inlier diffusion model and typicality testing. Our method (1) is grounded in statistical typicality,
and (2) is competitive with, and often more precise than, existing methods across diverse local OOD
detection tasks with complex inlier distributions.

PRELIMINARIES
In LACToS, we treat a diffusion model as an oracle denoiser that samples images consistent with its
training distribution and a noisy input image. We provide a brief introduction to diffusion models and
their use in posterior sampling in Appendix A. Here, we provide context on local OOD detection
methods proposed in prior work, some of which inspired our use of statistical typicality in LACToS.
OOD detection is studied at both the image and pixel (local) levels. Image-level OOD detection
assigns a single anomaly score to an entire image, with the goal of identifying images that are not
drawn from the inlier distribution seen during training. In contrast, we focus on pixel-level OOD
detection, in which the goal is to produce a dense anomaly heatmap to localize anomalous regions

within each image. Formally, given an image x⋆, the goal is to estimate the ground truth anomaly
mask m⋆. Previous works (Mousakhan et al., 2024; Wyatt et al., 2022; Defard et al., 2021) define
an anomaly score f(x⋆, j) that captures how likely each pixel j ∈J is to be OOD, where J is an
index set of size W × H over all pixels. Then, they compute an anomaly heatmap A with elements
Aj = f(x⋆, j) for each pixel, fix some threshold τ, and set ˆm = 1{A ≥τ}. Many of these works,
especially those using diffusion models, are reconstruction-based: they generate an in-distribution
reconstruction of the input using posterior sampling and use discrepancies such as ℓ1, ℓ2, SSIM (Wang
et al., 2004), LPIPS (Zhang et al., 2018), or feature-space distances as anomaly scores (Zavrtanik
et al., 2021; Wu et al., 2024; Mousakhan et al., 2024; Pirnay and Chai, 2022). Although effective,
these methods often collapse the distribution of plausible reconstructions into a first-order statistic,
such as the mean reconstruction error, which does not capture the full reconstruction distribution and
can reduce robustness to complex inlier distributions.

MOTIVATION
The local OOD detection problem has been extensively studied in the context of industrial defect
detection. Prior works such as PatchCore (Roth et al., 2022), EfficientAD (Batzner et al., 2024),
GLASS (Chen et al., 2024), and diffusion-based DDAD (Mousakhan et al., 2024) achieve excellent
performance on widely used benchmarks such as MVTec AD (Bergmann et al., 2019) and VisA
(Zou et al., 2022). However, we observe that these methods do not extend robustly to other OOD
detection tasks, such as tumor detection, facial anomaly detection, and security screening using X-ray
images, as shown in Table 1. One potential cause of this brittleness is the complexity of the inlier
distribution. Industrial defect-detection datasets often have very structured inlier distributions, as
products without defects are visually near-homogeneous, whereas CT scans, images of human faces,
and X-ray baggage scans are far more heterogeneous even in the absence of anomalies. Moreover,
defects in products are context-agnostic: a defective feature, such as a crack or fracture, is anomalous
regardless of where in the image or product it occurs. In contrast, a dark region in a CT scan may be
innocuous normal anatomy in one location, or indicative of a tumor in another.
Specifically, when the conditional distribution over a local region given the rest of the image is
multimodal, methods that rely on a first-order statistic may erroneously identify samples from a
different inlier mode as anomalous. To illustrate this phenomenon through a toy experiment, we
construct four inlier distributions with increasing complexity levels, and train a diffusion model
on each inlier distribution. Each image contains four shapes, one per quadrant. In the upper-right
quadrant, every inlier image contains a circle, which allows us to define all other shapes placed in that

FEATURE AUGMENTATION
One final problem remains (P4): RGB values alone may not distinguish local ID and OOD features.
To address this issue, (P4) we follow the convention of previous works (Mousakhan et al., 2024; Roth
et al., 2022; Defard et al., 2021) and augment RGB values with additional features. Specifically, we
extract the activations of the last three layers of a pretrained ResNet (He et al., 2016) ϕ, as later layers
of convolutional neural networks are known to encode higher-level visual structure and have been
widely used as transferable representations for downstream vision tasks (Razavian et al., 2014; Zeiler
and Fergus, 2014). The high activation dimension, denoted as Cf, can increase histogram estimation
error when few samples are available. We therefore use an autoencoder trained on each ID dataset to
compress the features to dimension C′
f(≪Cf); in our experiments we use C′
f = 3.

EVALUATION
Datasets.
We evaluate LACToS on three local anomaly detection datasets spanning medical imaging,
human faces, and X-ray security screening (Table 4). In each case, the diffusion model in LACToS is
trained only on ID images, and all methods are evaluated on a held-out test set. Each test set includes
an equal number of ID images and images containing local OOD features.
CHAOS (Kavur et al., 2019) provides abdominal CT scans of healthy patients. We train on 3,070
inlier slices and construct a test set containing 100 healthy test slices and 100 locally anomalous slices
acquired by adding synthetic tumor to each. Following common practice in CT image analysis (Wang
et al., 2021; Thummerer et al., 2023; Su et al., 2019), we apply the provided body mask at evaluation
to exclude background pixels. FFHQ (Karras et al., 2019) is a dataset of high-quality face images,
which we treat as the inlier distribution. We train on a random subset of 5,000 images, and manually
curate an OOD test set of 50 photographs of movie and television characters with prosthetics or
atypical facial features (e.g., scars, metal implants), verified not to overlap with FFHQ. The ID test
set contains 50 randomly selected held-out FFHQ images. DVXray (Ma et al., 2024) is a dataset
of X-ray luggage scans, with an ID set of weapon-free bags and an OOD set containing weapons.
We train on 5,000 inlier images and restrict the OOD test set to the scissors category, where targets
are small and spatially confined. For randomly sampled scissor images, we used SAM 3 (Carion
et al., 2026) to convert the dataset’s bounding-box annotations into segmentation masks, manually
discarding images with visibly inaccurate masks for a final OOD test set of 72 images. We construct
an ID test set that also contains 72 images, none of which contains a weapon.
Baselines & Models.
We compare LACToS against six strong baselines developed for industrial
defect detection, spanning representation- and reconstruction-based methods. PatchCore (Roth
et al., 2022) builds a coreset-subsampled memory bank of ID patch features from a frozen ImageNet-
pretrained backbone and scores test patches by nearest-neighbor distance. SimpleNet (Liu et al.,
2023) learns a feature adapter and a discriminator that separates adapted ID features from synthetic
