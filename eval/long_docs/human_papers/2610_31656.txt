ABSTRACT
Meta-reinforcement learning aims to train agents that adapt quickly to unseen
tasks from limited interaction, but this requires representing task evidence over
long interaction histories. Classical recurrent agents compress experience into
hidden states, while transformer-based agents retrieve from past trajectories at
quadratic memory and computation cost. In this work, we propose Memory-
Enhanced Test-Time Adaptation (METTA) for meta-reinforcement learning. It de-
composes the fast adaptation phase into two temporal scales: a causal neural mem-
ory performs fine-grained within-episode adaptation with linear sequence com-
plexity, while compact episode-level summaries support long-range cross-episode
task inference without attending over the full interaction history. Moreover, equip-
ping agents with neural memory provides sufficient expressive capacity and test-
time training capability, enabling effective adaptation to unseen held-out tasks and
task families at meta-test time. On unseen held-out Meta-World ML10/45 test en-
vironments, METTA achieves a success rate over 50% while maintaining a low
training budget and short wall-clock time. On long-context sparse-reward Point-
Maze tasks, it outperforms transformer-based baselines by exhibiting more struc-
tured exploration behavior. These results show that METTA provides an efficient
path toward more adaptive and scalable long-context meta-RL.

INTRODUCTION
Reinforcement learning (RL) studies how agents learn to make sequential decisions through in-
teraction with an environment, using rewards as feedback to improve future behavior (Sutton &
Barto, 2018). Despite strong performance in fixed environments, standard RL methods often require
large amounts of data to adapt to new tasks and generalize poorly under environment shifts (Packer
et al., 2018; Cobbe et al., 2019). Meta-reinforcement learning addresses this limitation by train-
ing agents over a distribution of tasks so they can use past training experience to adapt quickly
to unseen tasks from limited interaction at meta-test time (Duan et al., 2016; Wang et al., 2016;
Finn et al., 2017; Rakelly et al., 2019). A fundamental problem in meta-RL is representing task
evidence collected during interaction with the environment (Humplik et al., 2019; Zintgraf et al.,
2021). Black-box sequence-based agents learn this representation directly from trajectories using
internal dynamics (Duan et al., 2016; Wang et al., 2016; Mishra et al., 2018; Alver & Precup, 2021).
Latent-context methods instead make task inference more explicit by inferring a task variable or
belief from collected experience (Humplik et al., 2019; Rakelly et al., 2019; Zintgraf et al., 2021).
Yet despite their differences, most approaches still rely on compressed task representations, which
may restrict their capacity in meta-RL settings where task evidence may be sparse, delayed, or un-
evenly distributed across episodes. Once experience is compressed into a latent task representation,
the policy cannot easily recover specific past evidence that later becomes important.
Transformers offer a natural alternative because self-attention enables associative retrieval over past
interactions and supports long-range dependency modeling without relying on recurrent state com-

nals (Parisotto et al., 2019). In online meta-RL, the effective context grows with both the episode
horizon and the number of adaptation episodes, making full-history attention increasingly expensive
in memory and computation. As a result, transformer-based agents often face a trade-off between
retaining long histories and remaining computationally practical.
The computational overhead of full-history attention has motivated a recent shift toward modern
linear recurrent models and neural memory architectures (Gu et al., 2021; Smith et al., 2022; Gu &
Dao, 2023; Sun et al., 2023; 2025). Instead of attending over the full history, these methods update
an adaptive memory state online while preserving linear sequence complexity. Recent work suggests
that recurrence need not be limited to a small passive hidden state and can instead be equipped with
expressive state dynamics or trainable memory modules, allowing models to store information over
long horizons while preserving linear sequence complexity (Gu & Dao, 2023; Sun et al., 2025).
In particular, Test-Time Training (TTT) (Sun et al., 2025) treats memory as a trainable module
that can be updated continually during inference, turning sequence processing from passive state
compression into adaptive memory updating. This has led to promising results in settings where
long-range information is essential, including language modeling, time series, genomics, novel-
view synthesis, and video generation (Sun et al., 2025; Behrouz et al., 2025; Zhang et al., 2025;
Dalal et al., 2025).
In this work, we propose Memory-Enhanced Test-Time Adaptation (METTA), which leverages TTT
layers (Sun et al., 2025) as a modern neural memory module to gather task evidence from long-
range interaction sequences in meta-RL. Besides this within-episode memory module, which pro-
vides fine-grained episode-level memories, we also use a coarse-grained aggregation mechanism
that combines summaries across episodes. Thus, in addition to the classical slow and fast learning
processes in meta-RL, our fast adaptation phase separates within-episode adaptation from cross-
episode evidence aggregation, allowing the policy to condition on longer meta-test histories without
relying on quadratic computation over agent interaction steps.
Our experiments across locomotion, manipulation, and navigation benchmarks show that METTA
improves fast adaptation in both standard and long-context meta-RL settings. Interestingly, the rel-
ative gain over existing methods is especially notable when generalizing to unseen held-out Meta-
World task families that are not encountered during meta-training. This provides evidence of task-
family-level out-of-distribution generalization, where adaptation transfers to task families not ob-
served during meta-training. This suggests that neural memory modules can support adaptation
beyond the task families observed during training.

2.2
NEURAL MEMORY
Neural memory provides a common abstraction for sequence models that update an internal state
and read from it to produce predictions. This view includes recurrent networks, linear attention,
state-space models, and recent test-time memory architectures (Katharopoulos et al., 2020; Gu &
Dao, 2023; Sun et al., 2025; Behrouz et al., 2025). Given an input sequence x1:n, a memory model
maintains a state Mt = Uθ(Mt−1, xt) and produces an output yt = Rθ(Mt, xt), where Uθ is the
update rule and Rθ is the readout rule. This notation covers both fixed-size recurrent states and
richer memory states designed to store and retrieve information over longer horizons.

value, and query. Given learned projections kt = θKxt, vt = θV xt, and qt = θQxt, the memory
update and readout can be written in terms of key-value writing and query-based retrieval. In general,
the write and read operations can be expressed as

The distinction between inner-loop and outer-loop parameters is central to TTT. The memory pa-

sequence is processed, including at test time. In contrast, the view projections θK, θV , θQ, the initial
memory parameters, and the downstream network parameters are slow parameters learned across
training sequences. Thus, the outer loop learns how to construct a useful self-supervised update
rule, while the inner loop applies this rule online to adapt the memory to the current sequence.

METTA
In this section, we introduce Memory-Enhanced Test-Time Adaptation (METTA) for meta-RL.
We consider a trial-based meta-RL setting in which the agent interacts with multiple consecutive
episodes from the same sampled task. Each trial is generated from a hidden task T ∼p(T ) and
contains E episodes, each with horizon H.
At episode e and timestep t, the agent uses the interaction history to construct a context repre-
sentation ze,t that summarizes task-relevant evidence accumulated during adaptation. The policy
conditions on both the current state and this context representation for action selection,
ae,t ∼πψ (· | se,t, ze,t) .

at two temporal scales. A within-episode neural memory supports fine-grained online adaptation,
while a cross-episode memory aggregates information across episodes. Together, these modules

EXPERIMENTS
4.1
EXPERIMENTAL SETUP
Benchmarks.
We evaluate the effectiveness of our method on standard meta-RL benchmarks cov-
ering locomotion, manipulation, and navigation tasks. We evaluate continuous-control adaptation
on MuJoCo HalfCheetahVel (Todorov et al., 2012), where the agent must infer the target velocity
from interaction. We use a limited training budget to compare how efficiently each method adapts
under restricted environment interaction.
Next, we evaluate robotic manipulation on ML1, ML10, and ML45 from the Meta-World bench-
mark (Yu et al., 2020). In ML1, following the standard baseline convention, goal coordinates are
masked and must be inferred through interaction. ML10 and ML45 span multiple task families with
disjoint train and test splits, allowing us to evaluate generalization to families not observed during
meta-training. We view this as a form of task-family-level OOD evaluation, since the held-out test
families are encountered only at meta-test time. In these settings, goal coordinates are included in
the observation, while the task family remains fixed within each trial. During multi-class training,
each rollout batch assigns environments to task classes in a balanced way and then samples a task
variation within each class.
Finally, we use PointMaze (Fu et al., 2020) with sparse rewards (only at the goal position) to eval-
uate long-context adaptation. In this environment, the agent may need to explore for many steps
before receiving useful feedback, making it important to preserve information from earlier parts
of the trajectory. This benchmark directly tests whether meta-RL methods can benefit from long
context.
Baselines.
We compare METTA against representative meta-RL baselines from recurrent,
gradient-based, latent-context, and transformer-based families. RL2 uses recurrent state to imple-
ment black-box adaptation from interaction history (Duan et al., 2016), while MAML learns an
initialization that can be adapted with gradient updates (Finn et al., 2017). PEARL and VariBAD
represent latent-context approaches that infer task variables from collected experience (Rakelly
et al., 2019; Zintgraf et al., 2021). For transformer-based meta-RL, we compare against TrMRL,
which uses self-attention over trajectory context (Melo, 2022), ECET, which improves cross-
episode conditioning (Shala et al., 2025), and AMAGO, an in-context RL agent trained on long

MAIN RESULTS
In this section, we focus on standard evaluations of baselines using well-known metrics, average
return and success rate, and leave additional analyses, including ablation studies and qualitative
results, to Appendix G. Figure 3a reports HalfCheetahVel performance under a limited training
budget. The training curve shows that METTA improves rapidly with low training variance. The
episode-wise adaptation plot in Figure 3a shows that METTA maintains strong returns from the first
episode and remains stable across later episodes, suggesting that its neural memory can quickly infer
the target velocity from interaction.
4.2.1
ROLE OF LONG-CONTEXT MEMORY
Figure 3b shows that, in long-horizon tasks with sparse rewards, METTA rapidly improves the suc-
cess rate during both meta-training and meta-testing, while the other baselines remain substantially
lower. This suggests that METTA can preserve useful evidence from earlier exploration and reuse
it in later episodes. Transformer-based baselines (Melo, 2022; Shala et al., 2025) struggle in this
setting. TrMRL is difficult to scale to long effective horizons and tends to repeat similar exploration
behavior, while ECET is limited by short-context cross-episode conditioning. VariBAD improves
more slowly, likely because sparse rewards provide weak evidence for updating the latent task belief
until successful exploration occurs (Zintgraf et al., 2021).
