Predictable performance is suboptimal
and what it means for model routing
Guanhua Zhang*, Moritz Hardt
Max Planck Institute for Intelligent Systems, Tübingen
Tübingen AI Center
Abstract
Large language models (LLMs) differ in capabilities and costs, motivating routing methods
that adaptively choose a model for each query. These methods rely on performance prediction:
given a query, estimate whether a model will answer it correctly. Most routing methods train
separate predictors of candidate models’ performance to guide model selection. Our work
shows that performance prediction only beats a simple baseline when the candidate model is
suboptimal on the task or the performance predictor adds significant capacity relative to the
candidate model. Specifically, we take a model’s self-confidence, the probability it assigns to
its chosen answer, as a baseline and study how much a performance predictor can improve on
it. First, we show that any performance predictor that outperforms a model’s self-confidence
can be used to improve the model’s loss: the predictor’s advantage transfers exactly in log loss
through recalibration. Second, accounting for the predictor’s additional parameters, we bound
its advantage by the model’s suboptimality plus the gain from those parameters. Third, we
extend our theoretical results to two-model cascades, which route queries to a more capable
model when the first model is predicted to fail. Experiments with 16 language models on
four benchmarks show that predictors gain a larger advantage over self-confidence on more
suboptimal models. This advantage shrinks as models improve through finetuning. Cascading
exhibits the same two patterns: predictor-based routing offers larger gains over confidence-
based routing for more suboptimal models, and these gains diminish after finetuning. Code is
available at https://github.com/socialfoundations/performance-prediction.

Introduction
Performance prediction estimates whether a model answers a query correctly (Kadavath et al.,
2022; Shnitzer et al., 2024). These predictions can help routing systems decide when to trust an
answer and when to call a stronger model (Geifman and El-Yaniv, 2017; Chen et al., 2024). By
catching a weak model’s errors accurately, routing can achieve better performance at the same
cost. But what makes a model’s errors predictable, and what does that reveal about the model?
In this paper, we study the predictability of a model’s performance relative to a simple baseline:
the model’s self-confidence, the probability it assigns to its chosen answer. Our key observation is
that any predictor that beats self-confidence can improve the model by the same amount. This means that

1.1
Our Contributions
Suboptimality bounds excess predictability. We connect performance prediction and model
improvement through recalibration: replacing the model’s confidence in its chosen answer with
the predictor’s estimate, and normalising the rest. We call the predictor’s reduction in correctness
log loss relative to self-confidence excess predictability. Recalibration reduces the model’s answer
log loss by exactly the same amount (Proposition 1). We assume a scaling floor: the lowest answer
loss achievable on a fixed task at each parameter budget (Assumption 1). The recalibrated model
cannot beat the floor at the combined parameter budget of the model and predictor. This gives
the bound (Theorem 1)
excess predictability ≤suboptimality + capacity gain .
Here, suboptimality is the model’s gap to the floor at its own budget. The capacity gain is the
decrease in the floor from adding the predictor’s parameters.
Greater excess predictability comes with greater suboptimality. Our upper bound does
not imply that more suboptimal models are necessarily easier to predict beyond self-confidence.
Empirically, however, we observe a positive association between the two. We conduct experiments
on WinoGrande, CommonsenseQA, GSM8K, and MMLU-Pro, using 16 language models from eight
families, ranging from 7 to 12B parameters. Using the gap to the best observed answer loss on
each task as a proxy for suboptimality, we find a positive association with excess predictability on
all four tasks, with Pearson correlations of 0.98, 0.98, 0.93, and 0.65, respectively (Figure 1). We
also finetune the models, retaining the 59 model-task pairs whose development accuracy improves.

Answer loss falls in all 59 retained pairs and excess predictability falls in 55 (Figure 2), despite
training separate 4B predictors for the released and finetuned models.
Suboptimality bounds error capture beyond confidence routing. We extend our analysis
to two-model cascades, where a router decides when to escalate a query to a stronger model.
We compare a learned router with confidence routing, which escalates the weak model’s lowest-
confidence queries, at the same escalation rate. Any router that captures more weak-model errors
can be converted into a predictor with positive excess predictability, even if the router does not
explicitly estimate correctness (Lemma 1). This bounds the additionally captured weak-model
errors by weak-model suboptimality and the capacity gain from the router’s added parameters
(Theorem 2). The cascade accuracy gain equals the additional weak-model errors captured minus
the additional strong-model errors encountered. The same bound applies to the cascade accuracy
gain if the learned router encounters at least as many strong-model errors as confidence routing
(Corollary 2).
More suboptimal models have larger routing advantages. Using the same models and
predictors, we compare predictor-based routing with confidence routing at equal escalation rates.
We measure the routing advantage as the gain in cascade accuracy, averaged over escalation rates.
Models with greater empirical suboptimality tend to have larger routing advantages on all four
tasks, with Pearson correlations between 0.66 and 0.91 (Figure 4). This advantage shrinks after
finetuning in 53 of the 59 retained pairs (Section 4.3).
Main takeaway. Together, these results suggest three sources of predictability: the model’s self-
confidence, its suboptimality, and the predictor’s added capacity. Improving the underlying model
generally reduces the additional value of learned prediction and routing beyond self-confidence.

Related Work
Performance prediction. Performance predictors, also called assessors, estimate whether a system
will succeed on a given input (Hernández-Orallo et al., 2022; Zhou et al., 2022). They use model
outputs (Yao and Koller, 2024), reference evaluations and question features (Pacchiardi et al.,
2024), follow-up queries (Sam et al., 2025), or internal activations before the model answers
(Moreno Cencerrado et al., 2026). Kapoor et al. (2024) finetune language models on graded
answers to predict their own correctness and that of other models. Xiao et al. (2026) find that
models predict their own correctness no better than unrelated models do, and train predictors
that work across models. Beyond binary correctness, Hsu et al. (2025) estimate continuous quality
scores and uncertainty intervals for free-form generation. At the benchmark level, studies forecast
performance from training compute (Owen, 2024) or scores on other benchmarks (Ruan et al.,
2024). Others estimate benchmark scores from a small set of evaluated examples (Maia Polo et al.,
2024; Zhang et al., 2025a). We study where predictability on individual inputs comes from, using
self-confidence as the baseline and correctness log loss to measure a predictor’s advantage.
Model routing and cascading. Performance predictions help routing systems balance cost and
performance by choosing which models to use for each query (Ong et al., 2025). We use routing
broadly to include cascading, where a cheaper model answers first and a router uses its output
to decide whether to call a stronger model (Chen et al., 2024; Dekoninck et al., 2025). Routers
learn which model to use from preference data, as in RouteLLM (Ong et al., 2025), benchmark
3


results (Shnitzer et al., 2024; Mohammadshahi et al., 2024), or reward-model scores (Lu et al.,
2024). Some predict query difficulty to guide model selection (Ding et al., 2024). RouterBench
provides a common framework for evaluating routing methods (Hu et al., 2024). In cascades,
routing rules often escalate to a larger model when the first model has low confidence or gives
inconsistent answers (Varshney and Baral, 2022; Yue et al., 2024; Chuang et al., 2025). Learned
routing rules use token-level uncertainty and model embeddings (Gupta et al., 2024) or verify
the first model’s answer before deciding whether to escalate (Aggarwal et al., 2024). Wang et al.
(2024a) also improve cascades by training the first model to account for deferral. Dekoninck et al.
(2025) derive an optimal cascading policy and prove that an existing routing policy is optimal;
both depend on good estimates of answer quality. Jitkrittum et al. (2023) show when confidence
alone gives an optimal deferral rule and when a learned rule (Narasimhan et al., 2022) is needed.
We bound how many more of the first model’s errors a learned router can catch than confidence
routing under the same escalation rate.
Confidence and selective prediction. Language models can estimate whether their answers
are correct (Kadavath et al., 2022) through stated confidence (Tian et al., 2023; Xiong et al., 2024) or
agreement among sampled answers (Wang et al., 2023; Kuhn et al., 2023). Learned verifiers score
candidate solutions to select better answers (Cobbe et al., 2021; Lightman et al., 2024), and the
gap between generation and verification abilities is linked to self-improvement (Song et al., 2025).
Confidence also guides decisions about when to answer. Selective prediction uses it to decide
when to abstain (Chow, 1970; Geifman and El-Yaniv, 2017), while learning to defer also considers
whether another expert will be correct (Mozannar and Sontag, 2020). For selective prediction,
both calibration and how confidence ranks inputs matter (Rabanser and Papernot, 2025). Inputs
with the same confidence can still differ in their probability of correctness; grouping loss measures
this variation (Kull and Flach, 2015; Perez-Lebel et al., 2023). Melo et al. (2026) estimate grouping
loss and excess decision risk to guide LLM cascades, and find that grouping loss decreases with
model scale and instruction tuning. Our experiments examine how gains over confidence vary
with answer-loss suboptimality across models of similar size and before and after task-specific
finetuning.
Calibration and loss minimization. Language models can produce informative but poorly
calibrated risk scores (Cruz et al., 2024). Post-hoc calibration adjusts confidence to match observed
correctness (Platt, 2000; Guo et al., 2017; Kumar et al., 2019).
Multicalibration extends this
requirement to identifiable groups (Hebert-Johnson et al., 2018), including those defined by LLM
embeddings and self-annotations (Detommaso et al., 2024). Loss minimization and multicalibration
theory show how correcting predictable errors in probability estimates can reduce loss, including
squared loss and cross-entropy (Gopalan et al., 2022, 2023; Błasiok et al., 2024). We show that any
reduction in correctness log loss over self-confidence yields an equal reduction in answer log loss.
Under our assumptions for combining models and counting parameters, this gain is bounded by
the original model’s suboptimality plus the improvement possible with the added parameters.
3
Predictable Performance is Suboptimal
We show that gains over self-confidence transfer exactly to lower answer loss and are bounded by
model suboptimality and added predictor capacity. Proofs are deferred to Appendix A.1.
4


3.1
Problem Definition
Let (X, Y) be drawn from a fixed population, where X ∈X is the query and Y ∈Y = {0, . . . , K −
1} is the answer. A model f ∈F is defined as a conditional probability mass function f (y|x). Its
point prediction is ˆf (x) = arg maxy f (y | x), with ties broken by a fixed rule. We score any model
f by its answer loss LY( f ) = E[−log f (Y | X)].
We define the correctness indicator Z = 1{Y = ˆf (X)} ∈{0, 1}. A performance predictor g ∈G
is defined as a conditional probability mass function g(z | x) that may read f’s output on x. We
require full support, g(z | x) > 0, and score g by its correctness loss LZ(g, f ) = E[−log g(Z | X)].
The model’s self-confidence provides a natural baseline: any model f induces a performance
predictor fZ with fZ(1 | x) = f ( ˆf (x) | x). We abbreviate LZ( f ) := LZ( fZ, f ).
The goal of performance prediction is to minimize LZ(g, f ), where LZ( f ) serves as a baseline.
We call LZ( f ) −LZ(g, f ) the excess predictability achieved by g relative to f’s self-confidence; a
performance predictor is effective when its excess predictability is positive.

Additional results.
First, under diminishing returns, a predictor much smaller than the model
has excess predictability bounded by the model’s suboptimality plus a small capacity correction
(Corollary 1, Appendix A.3). Second, suboptimality does not determine excess predictability:
lowering answer loss does not necessarily lower correctness loss. Models can have the same maxi-
mum excess predictability yet differ in suboptimality because they assign different probabilities to
the answers they do not choose (Proposition 3, Appendix A.4).
3.4
Experiments
Motivated by the preceding bound on excess predictability, we study two empirical questions on
16 language models across four benchmarks. Do more suboptimal models exhibit greater excess
predictability over self-confidence? Does task-specific finetuning reduce this advantage?

3.4.1
Setup
Models and tasks. We evaluate 16 base and instruction-tuned models from eight families, with
7 to 12B parameters. We select four tasks, WinoGrande (Sakaguchi et al., 2020), CommonsenseQA
(Talmor et al., 2019), GSM8K (Cobbe et al., 2021) and MMLU-Pro (Wang et al., 2024b). WinoGrande and
CommonsenseQA are evaluated by scoring answer options, and GSM8K and MMLU-Pro are evaluated
by generating answers. The binary task WinoGrande is a sanity check: predicting a fixed model’s
correctness is equivalent to predicting the answer. Appendix B.1 lists model releases and data
splits, shared across models.
Evaluation. We use five-shot evaluation with lm-eval-harness (Gao et al., 2024). The answer
distribution f (· | x) comes from normalized option likelihoods on the first two tasks and answer
frequencies from 128 sampled solutions per question on the generation tasks. We select the
highest-probability answer ˆf and use its probability as self-confidence. On test questions, we
measure answer log loss LY( f ) and correctness log loss LZ( f ); cascades are evaluated by accuracy.
Appendix B.2 details scoring, sampling, answer extraction, and probability estimation.
Finetuning. We use LoRA (Hu et al., 2022) to finetune on gold answers for the option-
scoring tasks and on reasoning traces by Qwen3.5-122B-A10B for the generation tasks, selecting
checkpoints on development performance. Our experiment design is built upon the idea that
task-specific finetuning reduces suboptimality. Therefore, for each task, we consider all models
whose development accuracy does not improve after finetuning to be anomalous and remove the
corresponding model pairs from the analysis. This leaves 16, 16, 14, and 13 model pairs for the
respective tasks. Appendix B.3 gives training and retention details.

Suboptimality Bounds Cascading
In a cascade, a router decides which queries to send from a weak model to a stronger model.
We compare a learned router with the weak model’s self-confidence at the same escalation rate.
Cascades are judged by accuracy at that rate, so this section bounds error rates rather than log
loss. The key connection is that a router that finds more weak-model errors also supplies a better
performance predictor. Proofs are deferred to Appendices A.5–A.7.
4.1
Cascading Setup
Let f1 ∈FP1 and f2 ∈FP2 be the weak and strong models, with P1 < P2 and LY( f1) < ∞. For
i = 1, 2, write Zi = 1{Y = ˆfi(X)} and ϵi(x) = Pr(Zi = 0 | X = x) for correctness and the actual
error probability. The weak model estimates its error probability by f1,Z(0 | x) = 1 −f1( ˆf1(x) | x),
assumed strictly between zero and one almost surely.

answer. Self-confidence routing applies the same rule to f1,Z(0 | x), giving Bf,ρ. At a fixed rate,
