ABSTRACT
Standard implementations of softmax, log-softmax, and cross-entropy have two
numerical bugs. The first bug, Softmax Collapse, rounds the target logit’s gradient
to zero if that one logit is much larger than the others, resulting in gradients that
no longer sum to zero. The second bug, Softmax Cancellation, occurs when stu-
dent logits are close to teacher logits, and produces non-zero gradients even when
the student and teacher logits are equal. We present simple implementations of
log-softmax, softmax, and cross-entropy that fix both bugs. Our fix eliminates the
previously-observed “Slingshot” phenomenon, speeds up grokking with weight
decay, prevents accuracy collapse without weight decay, stops student networks
from drifting away from the teacher during distillation, and shows that after mem-
orization, logit growth is bounded by an equilibrium between weight decay and
Adam’s ϵ hyperparameter.

rounds to 0.0 while the non-target gradients do not, the gradients no longer sum to zero (P

When training with adaptive optimizers such as Adam and AdamW (Kingma & Ba, 2015; Loshchilov
& Hutter, 2019), which normalize each gradient by a moving average of its magnitude, this asymmetry
causes the recurring “Slingshot” loss spikes observed by Thilak et al. (2022) and the grokking failures
studied by Prieto et al. (2025). While prior works used surrogate losses (Prieto et al., 2025), gradient
projection (Liu et al., 2026), or fp64 casting (Nanda et al., 2023; Varma et al., 2023) to mitigate these
issues, we instead fix log-softmax, softmax, and cross-entropy directly (Section 2).
The second bug, Softmax Cancellation (Figure 1b), occurs in knowledge distillation (Hinton et al.,
2015) and KL regularization, where the target p = softmax(zT) comes from teacher logits zT.
Standard implementations compute q = softmax(zS) and p = softmax(zT) separately and subtract
them to get ˜g = q−p. This means that if zS is close to zT, subtracting these nearly equal probabilities
loses precision, and slight differences between the forward-pass softmax and backward-pass log-
softmax formulas leave a non-zero gradient even when zS = zT. We fix this by computing q −p
directly from zS −zT in log space (Section 3).

import jax, jax.numpy as jnp, optax
def log_softmax(z):
i_max = jnp.argmax(z, axis=-1)
z_max = jnp.take_along_axis(z, i_max[..., None], axis=-1)
# Max logit.
is_max = jax.nn.one_hot(i_max, z.shape[-1], dtype=bool)
# Max mask.
shifted = jnp.where(is_max, 0.0, z - z_max)
# Exact 0 at argmax.
others = jnp.where(is_max, -jnp.inf, shifted)
# Exclude argmax from sum.
m = -jax.nn.logsumexp(others, axis=-1, keepdims=True)
# Logit margin.
return shifted - jax.nn.softplus(-m)
# log_softmax(z).
softmax = lambda z: jnp.exp(log_softmax(z))
def cross_entropy(z, t):
z_t = jnp.take_along_axis(z, t[..., None], axis=-1)
# Target logit.
is_t = jax.nn.one_hot(t, z.shape[-1], dtype=bool)
# Target mask.
others = jnp.where(is_t, -jnp.inf, z - z_t)
# Exclude target from sum.
m = -jax.nn.logsumexp(others, axis=-1)
# Logit margin.
return jax.nn.softplus(-m)
# -log_softmax(z)_t.

As the student logits approach the teacher logits (zS →zT), the true gradient g = q −p shrinks
toward 0 and equals 0 when zS = zT. In floating point, however, computing q and p separately
and subtracting them (Equation 8) loses precision when zS is close to zT, because the small logit
difference δ = zS −zT is lost when q and p are rounded to probabilities before being subtracted
(Figure 1b). Worse, because p = softmax(zT) in the forward pass and q = exp(logsoftmax(zS))
in the backward pass are evaluated using slightly different sequences of operations, q and p do not
match to machine precision even when zS = zT, leaving a non-zero gradient ˜g = q −p̸ = 0.
To avoid subtracting nearly equal probabilities, we pass zT directly to our loss function and compute
q −p in log space using expm1(x) = ex −1 and log1p(x) = log(1 + x). Given δ = zS −zT, we

def soft_target_cross_entropy(z_S, z_T):
log_q = log_softmax(z_S)
q, p = jnp.exp(log_q), softmax(z_T)
delta = z_S - z_T
# Logit difference.
d = delta - jnp.sum(p * delta, axis=-1, keepdims=True)
# Center under p.
s = d - jnp.log1p(jnp.sum(p * jnp.expm1(d), axis=-1, keepdims=True))
# log(q / p).
u = p * jnp.expm1(s)
# Difference q - p.
g = u - q * jnp.sum(u, axis=-1, keepdims=True)
# Ensure sum(g) = 0.
sg = jax.lax.stop_gradient
loss = -jnp.sum(p * sg(log_q), axis=-1)
# Forward loss.
return loss + jnp.sum(sg(g) * (z_S - sg(z_S)), axis=-1)

THE SLINGSHOT MECHANISM
In grokking (Power et al., 2022), a network quickly memorizes the training set (qt →1) and
generalizes much later. While studying grokking on modular addition with Adam (Kingma & Ba,
2015; Loshchilov & Hutter, 2019), Thilak et al. (2022) observed the Slingshot Mechanism, where
training after memorization alternates between flat loss plateaus near zero and sudden loss spikes that
coincide with jumps in test accuracy.
These Slingshot spikes are a direct consequence of Softmax Collapse (Section 2). Recall that AdamW
updates parameters θ by subtracting η

After memorization, the logit margins m grow as the network pushes its target probabilities toward 1.
Once an example’s margin exceeds the precision cliff cd, standard cross-entropy rounds its target
gradient ˜gt to zero while its non-target gradients ˜gj > 0 (j̸ = t) remain positive. When all examples
in a batch sit above cd, the parameter gradients nearly vanish and Adam’s second moment ˆvi decays
exponentially toward zero while weight decay slowly shrinks the parameters. Eventually, weight
decay or the residual non-target updates pull a few examples back below cd, where their target

Whether Slingshot spikes appear to help or hurt generalization depends on how the network’s weight
norm is controlled (Figure 2). When a network uses LayerNorm before the output layer and no
weight decay (Thilak et al., 2022; Prieto et al., 2025), growing the pre-LayerNorm weights does not
change the logits, but it does shrink the effective step size η/∥θ∥2; each Slingshot spike inflates ∥θ∥2
and acts as an accidental learning-rate decay. When weight norms are already controlled by weight
decay (Varma et al., 2023), Slingshot spikes at c32 only slow down and hurt grokking (94 ± 5% vs.
100 ± 0% test accuracy on a + b mod 31; Figure 2, top). And when neither LayerNorm nor weight
decay is used (Doshi et al., 2024), a single Slingshot spike at c32 is destructive: on a2 + b2 mod 97
(λ = 0, ϵ = 10−16), standard cross-entropy tracks fixed cross-entropy up to 61% test accuracy until
m hits c32 around step 1250, where a spike drops test accuracy to 23% (and from 60% to 21% on
a3 + b mod 97), while fixed cross-entropy continues smoothly to 85% (Figure 2, bottom).

GROKKING ACROSS PRECISIONS AND BENCHMARKS
To see how the precision cliff behaves across floating-point formats, we follow Varma et al. (2023)
and Lyle et al. (2025) and train a 1-layer width-64 ReLU Transformer on a+b mod 31 (50% training
split) for 10,000 epochs of full-batch AdamW with η = 10−3, β1 = 0.9, β2 = 0.98, and λ = 1. We
vary only the loss function (standard vs. fixed cross-entropy), the floating-point precision (bf16, fp32,
fp64), and ϵ ∈{10−8, 10−12, 10−16} (Figure 5, Table 1). At ϵ = 10−8 (Figure 5, top), standard
cross-entropy stalls at c16 ≈5.5 in bf16 and repeatedly spikes at c32 ≈16.6 in fp32, whereas our
fixed cross-entropy crosses both cliffs smoothly to the equilibrium log(1/ϵ) ≈18.4 and reaches 100%
test accuracy in all three precisions. Reducing ϵ to 10−16 (Figure 5, bottom) raises the equilibrium to
6
