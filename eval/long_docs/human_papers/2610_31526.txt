Direct Inference on Admissible Sets (Diona)
Lorenzo Sabug Jr.∗, Eric Kerrigan
Abstract
We propose a new regression method named Direct Inference on Admissible Sets
(Diona) that directly uses samples to estimate the state and its derivatives at
a query point, along with their admissible bounds, without long global training.
By casting the values and derivatives at the query and neighbouring samples
as latent variables in a constrained optimisation problem, the burden of long
training loops becomes one of on-demand local solves. We establish Diona’s
theoretical properties including finite-sample coverage and, in the noiseless case,
convergence to the true state and derivatives under dense sampling. In a nonlin-
ear regression benchmark on six functions of three to eight dimensions, Diona
was more accurate than a Gaussian process (GP) on noiseless data especially
with denser data sets. Furthermore, as with GP, it produced uncertainty bounds
that contained the true value at more than 95% of query points in four func-
tions. Diona’s time to a first prediction after a data set update was three to
four orders of magnitude shorter than that of the GP, and two to three orders
shorter than that of a neural network, which was more accurate but offers no un-
certainty quantification. This low latency is paid for by on-demand predictions,
so this latency advantage applies when relatively few predictions are needed
between data updates.

1. Introduction
The reconstruction of a hidden function from existing samples is a long-
standing problem across science and engineering, especially when acquiring sam-
ples proves expensive and/or challenging, e.g., in computational fluid dynam-
ics, wireless sensor networks-based data gathering, or robot-based exploration.
Such a problem, referred to as “data-driven regression” or “interpolation”, is a
well-investigated topic [1], addressing the need for fast, accurate, and reliable
estimates.
There have been many previous works on data-driven regression, with clas-
sical methods relying on basis function fitting [2, 3], kernel functions [4, 5],
training parametric surrogate models, e.g., neural networks [6]. However, there
is need to choose/build a function library, kernel, and/or an architecture, which
is consequential for the resulting accuracy and computational burden. Another
class of methods rely on direct samples weighting [7, 8], which however do
not account for quadratic and/or curvature-related trends, affecting prediction
accuracy for reconstructing nonlinear functions from sparse samples. Other ap-
proaches do not assume nor fit an a priori known/designated function form,
and choose their estimates from an admissible set. Examples include nonlinear
set membership (NSM) methods [9, 10], Lipschitz-based interpolation [11], and
kinky inference [12], whose heritage we take for our proposed method. Aside
from point-value estimates, uncertainty quantification is investigated in different
forms in [9, 12, 5, 2], among others, a relevant quantity for exploration-based
sampling.
In many compelling applications like emergency response and robotic explo-
ration, rapidly accumulated samples and evolving data sets must influence the
next decisions, e.g., to take an action or select the next sampling points. For ex-
ploration in particular, the uncertainty measure is also a mission decision metric,
rather than a post hoc reported quantity. Therefore, there is demand for ap-
proaches that balance accurate predictions, informative and tight uncertainty
bounds, and computational efficiency: in particular, a low latency between a
2


data set update and a prediction.
This paper proposes a new formulation to use local information to estimate
the state at a prediction point (also referred to in this paper as ‘query point’).
Without assuming a functional form nor parametrised model, we use regular-
ity assumptions on the underlying functions and draw the Taylor relationships
between the query point and neighbouring samples, computing the admissible
set of state values and derivatives. Our method builds on NSM, kinky infer-
ence, and Lipschitz interpolation, but they only exploit a first-order regularity
assumption, so their uncertainty bounds grow linearly with distance from the
closest sample. Our method, on the other hand, uses a Lipschitz-continuous Hes-
sian with latent gradients and Hessians; these account for the local curvature
leading to uncertainty that shrinks with the cube of the sample neighbourhood
radius in the noiseless case. Our contributions are the following:
• We cast the regression problem as a joint set estimation of admissible
values and derivatives, using only (zeroth-order) function value samples,
and regularity assumptions. As a result, we arrive at a point estimate,
and the uncertainty bounds on the state and its derivatives.
• We derive the information radius—not just on the value estimate at the
query point, but also its derivatives—for the function smoothness class we
consider. Furthermore, in the noiseless case, we establish consistency on
the value and derivatives as the samples set becomes dense.
• We use our results to build a practical regression algorithm which, given a
samples set and a query point, solves small linear programs to simultane-
ously estimate the state and derivatives, as well as their corresponding un-
certainty bounds. Our new Direct Inference on Admissible Sets (Diona)
needs no offline training: every prediction is a per-query, on-demand solve,
and therefore does not require any retraining in face of evolving (appended,
changed) data sets.
We tested Diona in a nonlinear regression benchmark involving six functions
3


of three to eight dimensions against a Gaussian process (GP), a neural network
(NN), nonlinear set membership (NSM), radial basis functions and inverse dis-
tance weighting. In the noiseless cases, Diona had lower errors than the GP
especially with the densest data sets. It also gave tighter uncertainty bounds
than NSM while covering the true value within those bounds at more than 95%
of query points in four functions, similar to GP. In noisy cases, Diona’s accuracy
advantages were swept away, although it remained competitive with the other
methods. Furthermore, in the time that the GP needs to train, Diona pro-
duced around 104 predictions (102–103 predictions within the training time of
a GPU-trained NN). Diona’s timing advantage pays off in regimes where data
sets change often and relatively few predictions are needed between updates.
A preliminary version of this work appeared as Direct Constraints Based
Regression (DCBR) in [13].
In relation to that work, we have significantly
simplified the formulation, treated uncertainty quantification, investigated the
theoretical properties, discussed implementation-related aspects, and performed
a more exhaustive and detailed benchmark. The pertinent code base for Diona,
along with the benchmark scripts, is available on GitHub under the following
URL: https://github.com/lorenzosabugjr/Diona.

4. Implementation notes
We tackle here practical workarounds for settings where we do not satisfy
Assumptions 1-3. We use a combination of samples-based estimation of ϵ, LH
and a greedy poised neighbours selection approach.

bound ¯ϵ are not a priori known, and must be estimated from the data set
X⟨n⟩. To estimate ¯ϵ, any preferred method can be used, and here we use the
set membership-based approach from [15], to which we refer the reader for more
information.

4.2. Practical neighbour selection
Selecting a minimum-radius µ0-poised neighbour set to satisfy Assumption 3
is combinatorial w.r.t. the samples, and can be computationally prohibitive.
Therefore, we have built a simple greedy method to collect the neighbours set.
This involves starting from a nearest samples set as initial candidates for se-
lection, and building a neighbours set achieving a full-rank feature matrix ΦC.
From this neighbours set, we then iteratively add further samples to achieve the
µ0-poisedness.
Upon empirical testing, we opted for three passes of Algorithm 1 (each suc-
cessive pass excludes previously selected samples), and use the union of all such
neighbour samples to provide redundancy for computing ˜LH and u′, and u′.
This is to achieve a more informative ˜LH estimate4 and more reliable bounds
especially under noise. With a priori known ϵ and LH, Lemma 2 still holds for
the first neighbour set as the succeeding neighbour “layers” only serve to add
more constraints.
